# Multi-Turn Agentic Safety Evaluation: Extending Tool-Primed Adversarial Prompting Beyond Single-Turn Refusal Metrics

The gpt-oss-redteam project evaluated LLM safety vulnerabilities through paired adversarial prompts—comparing plain-text malicious requests against semantically equivalent tool-centric variants (e.g., `db.lookup`, `email.send`)—with each model response classified using a strict binary refusal metric based on exact string matching against a canonical refusal template. Across 15,600 generations spanning 52 high-level prompts and three system configurations, the methodology revealed that tool-framing reduced refusal rates by 15-42 percentage points, with statistical significance established using Wilson 95% confidence intervals and category-specific analysis across fraud, discrimination, hate speech, and eleven other intent types. The pipeline operates entirely locally via Ollama, generating prompts from human-designed templates, logging full response objects to JSONL, and computing aggregate metrics with per-category breakdowns. However, current evaluation is single-turn only—the model responds once and we classify—whereas real agentic systems execute tools, observe results, and continue. This proposed extension introduces simulated tool execution returning synthetic feedback (success/failure), multi-turn harm tracking to assess whether models escalate after seeing "successful" intermediate results, dynamic tool manifests that evolve mid-conversation, and cross-architecture benchmarking across Llama, Mistral, Qwen, and Phi families. This directly addresses the paper's identified limitation: fixed manifests and binary classification cannot capture procedural harm chains across conversation turns.
